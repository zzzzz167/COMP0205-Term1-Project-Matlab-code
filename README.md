# Wall-Gap Climber — MATLAB Models

MATLAB modelling and analysis for a manually powered wall-gap climbing mechanism, developed for **COMP0205 Mechatronics and Making** at UCL.

## Project Aim

Design a purely mechanical device that climbs between two walls using alternating upper and lower clamps and a central extension mechanism.

Design targets:
- Approximately **500 mm** cumulative vertical climb.
- Wall gaps ranging from **160 to 260 mm**.
- Stable support during climbing and when the hand crank is released.

## Scope

This repository contains MATLAB code for mechanism geometry, motion analysis, force estimation, and generating figures for the project reports.

The models are under development.

## Usage

Download or clone this repository and open the relevant scripts in MATLAB. Check each script for input parameters, assumptions, units, and any required toolboxes before running it.

MATLAB version and toolbox requirements will be documented as the models are added.
